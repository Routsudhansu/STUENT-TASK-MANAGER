# 🎓 Student Task Manager

A simple Python-based task management application designed for students to add, view, complete, and delete their tasks.

## 🚀 Features

- ➕ Add new tasks
- 👀 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Store tasks using JSON
- 🖥️ Simple command-line interface

## 🛠️ Technologies Used

- Python 3
- JSON
- Git
- GitHub

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
